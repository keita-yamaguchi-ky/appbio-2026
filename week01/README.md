### Assignment 1: What version is the samtools command in your bioinfo enviroment?
After checking Pixi documentation, I learned that I can find installed packages in an environment with list (ls):

Checking installed packages in `bioinfo`
> pixi list

Navigating down the list to find `samtools`
> samtools 1.25

Therefore, currently installed version of samtools is  1.25. 

Alternatively, this was confirmed by:
> samtools --version
